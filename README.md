# make.fun news image, November 18, 2026

Contest entry for the make.fun news-image challenge: one newspaper front-page
image summarizing the world news of November 18, 2026.

## Entry

- `entry.png`, the contest image (PNG, max 1024x1024 px, max 1 MiB).
- `main.ts` at the repo root: a Node 22 program (standard library only) that
  copies `entry.png` beside it to `/output/entry.png`, or to
  `$MAKEFUN_OUTPUT_DIR/entry.png` when that env var is set.

Run it with:

```sh
node main.ts
```
